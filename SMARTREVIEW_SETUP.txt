# 🚀 SmartReview - Google Review Generator Setup

## 📋 Project Created Successfully!

Location: ~/google-review-generator

## 🔗 Push to GitHub (SmartReview Repository)

### Step 1: Create GitHub Repository
1. Go to: https://github.com/new
2. Repository name: SmartReview
3. Description: QR/NFC Google Review Generator with AI
4. DO NOT initialize with README
5. Click "Create repository"

### Step 2: Push Code
Run these commands in terminal:

```bash
cd ~/google-review-generator
git remote add origin https://github.com/YOUR_USERNAME/SmartReview.git
git branch -M main
git push -u origin main
```

Replace YOUR_USERNAME with your GitHub username.

## 🌐 Deploy to Vercel

### Step 1: Import to Vercel
1. Go to: https://vercel.com
2. Sign in with GitHub
3. Click "Add New Project"
4. Import from GitHub → Select SmartReview
5. Click "Import"

### Step 2: Add Environment Variables
In Vercel project settings → Environment Variables:

```
OPENAI_API_KEY=sk-... (from https://platform.openai.com/api-keys)
GOOGLE_API_KEY=AIza... (from https://console.cloud.google.com/apis/credentials)
GOOGLE_PLACE_ID=ChIJ... (find in Google Maps URL)
BUSINESS_NAME="Your Business Name"
BUSINESS_TYPE="restaurant" (or your business type)
NEXTAUTH_URL=https://your-app.vercel.app
NEXTAUTH_SECRET=random_string_here
```

### Step 3: Deploy
1. Click "Deploy"
2. Wait for build to complete
3. Click "Visit" to see your live app
